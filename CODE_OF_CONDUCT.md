# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good faith, and keep discussion about the work.

To report unacceptable behaviour, contact the maintainers privately through a
[private advisory](https://github.com/faizm10/opsrelay-agent/security/advisories/new) (it reaches the
maintainers only, and is not limited to security issues). Reports are handled confidentially.
